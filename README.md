### 1.标题修饰符 ###

使用\#包含标题，\#数量决定字体大小

正文内容直接编辑，换行使用\<br>标签进行换行（某些编译器不写\<br>不换行）

### 2.文本修饰 ###

1.使用\*包含，一对\*为斜体  *斜体*

​                         两对为粗体  **粗体**

​                         三对为粗斜体 ***粗斜体***

2.两对~包含文本，~~删除线~~

3.\`\`,`凸显效果加灰底`

4.5个\*****,分割线

*****

### 3.列表 ###

使用\*空格+文本=>无序列表，列表可以有多级，子集列表要用缩进

* 列表
  * 子集
    * 三级

数字 空格+文本=>有序列表

1 一级

2 二级

3 三级

### 4.引用 ###

使用\>空格文本为一级引用, \>数量越多引用级别越高

> 123

> > fwf
> >
> > > iwjwi
> > >
> > > > cwjnk
